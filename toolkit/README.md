# Toolkit – deterministic DOM video engine

Renders HTML scenes frame by frame in headless Chromium (Playwright + CDP screenshots) and encodes them
with ffmpeg into MP4 clips (default 1920×1080, 30 fps), then joins the clips into one video. The engine
animates existing DOM – recreated HTML, real components in a harness, or a real app – with a camera,
a cursor, click ripples, highlights, modals, typing and voice-synced timing.

## Deterministic rules

Every frame is a pure function of `t`: `DEMO.seek(t)` must give the same picture whatever was seeked
before, in any order, in any browser page.

- No CSS transitions or animations (`base.css` forces `transition: none; animation: none` on everything).
- No `requestAnimationFrame` loops, timers, `Date`, `performance.now()` or `Math.random()` in scene code.
  Pseudo-randomness must be derived from an index (see `typingTimes`).
- State functions set every style they touch on every call (no "only when it changes" logic that
  depends on the previous frame; `setText`/`setHTML` only skip identical writes).
- Fonts and images are local files. No network at render time.
- Scenes are classic scripts loaded from `file://`; ES modules do not load there.

## Project layout

A video project is `<project>/video/`: a copy of this folder plus the project's own files.

```
video/
├── engine.js  base.css  fonts/  explode/  tools/      toolkit (do not edit per project)
├── render.mjs  assemble.mjs  package.json  pnpm-workspace.yaml  video.config.json  .gitignore
├── scenes/NN-slug.html         one scene per clip (helpers for a scene group: scenes/_lib-<group>.js)
├── shared/product.css          look-and-feel CSS (start from product.template.css)
├── shared/voice.js             GENERATED by tools/voice-meta.mjs – never edit
├── shared/voice.json           GENERATED, same data as voice.js, for Node/Remotion
├── shared/components.js        HTML builders with stable data-* selectors
├── shared/data.js              the fictional data story (optional DATA.scenes[n] = { slug, duration })
├── audio/                      one voice file per voiced scene (+ voice-script.txt): NN-slug.wav from pnpm tts or ElevenLabs files
│                               (+ <file>.words.json: measured word times from pnpm align)
├── clips/                      NN.mp4 per scene (render output, input to assemble)
└── stills/                     PNG stills and boundary-check frames
```

`tools/` also holds `cue.mjs`: the engine's `makeCue` as an ES module, plus `sceneInfo` for `shared/voice.json`
(for Node scripts and Remotion; see Voice below), `tts.mjs` (offline Kokoro voice, `pnpm tts`),
`contact.mjs` (contact-sheet planning and layout, `pnpm contact`), `captions.mjs` (SRT captions, `pnpm captions`), `align.mjs` (measured word times, `pnpm align`),
`ffbin.mjs` (the bundled ffmpeg runner, `pnpm ffmpeg`), `config.mjs` (config loading shared by every script), `browser.mjs` (browser launch with fallback), `doctor.mjs`,
`validate-links.mjs` and the tests.

`examples/` is a runnable example project with its own `video.config.json` (`dirs.scenes: "."`, `theme: "spotlight"`):
`01-example.html` (silent, fixed times), `02-voiced.html` (voiced, every time from `sceneInfo(2)` and `cue`),
`audio/voice-script.txt`, `make-audio.mjs` (synthetic voice) and `run.mjs` (`pnpm example`). Generated there:
`audio/02-voiced.mp3`, `shared/`, `clips/`, `stills/`, `example.mp4`.

## Setup

```bash
cd <project>/video
pnpm install                       # playwright-core (no bundled browser) + the ffmpeg binary (ffmpeg-static) + kokoro-js
pnpm doctor                        # Node ≥ 22, ffmpeg, a launchable browser, fonts – one ✓/✗ line each
```

Requires Node 22+ (`engines.node`) and pnpm. `pnpm install` downloads ffmpeg once (ffmpeg-static, GPL build,
~45 MB, needs network the first time). For offline installs, `FFMPEG_BIN=/path/to/ffmpeg pnpm install` makes
its install script use a local binary. `pnpm example` renders the bundled example project end to end
(see Commands) – the quickest proof that a new machine works.

- Browser: an installed Chromium-family browser; nothing is downloaded. The configured channel
  (`browser.channel`, default `"msedge"`) is tried first, then the others in the order msedge → chrome →
  chromium, with one log line when a fallback is used. Any other Chromium: `browser.executablePath` in the
  config, or `CHROME_PATH=/path/to/chromium` (wins over config; an explicit path never falls back).
- ffmpeg comes from `ffmpeg-static` via `pnpm install` (`pnpm-workspace.yaml` approves its install script).
  Override with `FFMPEG_PATH=/path/to/ffmpeg` (e.g. a Homebrew build). No ffprobe is needed. ffmpeg is used
  for clips, voice-meta, boundary checks (frames are decoded with ffmpeg for comparison) and assemble.
  Stills and the live preview need no ffmpeg.
- Offline voice (optional): `pnpm install` also installs `kokoro-js` (Kokoro-82M on the CPU via
  onnxruntime-node; ~410 MB in `node_modules`). The first `pnpm tts` downloads the model once from
  Hugging Face (fp32 326 MB) into a cache shared by all projects: `KOKORO_CACHE_DIR`, else
  `~/.cache/skill-c2v/kokoro`. After that it needs no network. English voices only; see
  `../tools/kokoro.md`. Rendering, voice-meta and assemble never touch the network or the model.
- Measured word times (optional): `pnpm align` runs Whisper through `@huggingface/transformers` (already
  installed with kokoro-js). The first run downloads `onnx-community/whisper-base_timestamped` fp32 (~291 MB)
  into `WHISPER_CACHE_DIR`, else `~/.cache/skill-c2v/whisper`; offline after that. On an Apple-silicon CPU it
  takes ~0.05 s per second of audio.

## Config reference (`video.config.json`)

Found as `--config <file>` or the nearest `video.config.json` in the scene's folder or a parent.
Paths are relative to the config file. Keys starting with `_` are comments. Defaults (`tools/config.mjs`):

| Key | Default | Meaning |
|---|---|---|
| `name` | `"product-demo"` | label only (not read by the scripts) |
| `output` | `"product-demo.mp4"` | final video written by assemble |
| `fps`, `width`, `height` | `30`, `1920`, `1080` | output format (viewport and stage size) |
| `lead`, `tail` | `0.5`, `0.8` | seconds before / after the voice in a voiced scene |
| `page` | `{ "w": 1670, "h": 940 }` | size of the unzoomed app page (`#page`, `#camera`) |
| `camBase` | `null` → `{ s: 1.15, cx: page.w/2, cy: page.h/2 }` | base camera |
| `cursorRest` | `null` → `{ x: 1660, y: 980 }` | default cursor position (stage px) |
| `hover` | `null` → `.hoverable, [data-hover], button, [role=button], .btn, .tab, .opt, .btn-close` | hoverable selector |
| `columnTable` | `null` → `"table"` | table used by `columnRect` / highlight `col` |
| `theme` | `null` → base (`"frame"`) + warning | overlay shape and motion: preset name (`"calm"`) or `{ "preset"?, "highlight", "cursor", "ripple", "camera", "modal", "typing" }` – see [ENGINE-API.md](ENGINE-API.md) › Themes |
| `fonts` | `["Inter"]` | families that must load (string or `{ "family": … }`) |
| `dirs` | `{ scenes, clips, stills, audio }` = same names | folders |
| `voiceOut` | `"shared/voice.js"` | generated voice metadata |
| `voiceText` | `null` | text file, one blank-line-separated paragraph per voiced scene |
| `audioPattern` | `"auto"` | `"auto"` = file in `audio/` whose name starts with the scene id (`1_Chapter_1.mp3`, `01-intro.mp3`); or a pattern with `{n}` id, `{nn}` 2-digit id, `{slug}`, `{i}`/`{ii}` position among voiced scenes |
| `browser` | `{ "channel": "msedge", "executablePath": null, "args": [] }` | browser to launch; `args`: extra Chromium flags, e.g. GPU flags for Three.js |
| `encode` | `{ crf: 14, preset: "slow", capture: "jpeg", quality: 95 }` | per-clip x264 settings and frame capture format |
| `assemble` | `{ crf: 16, preset: "slow", lufs: -16, truePeak: -1.5, lra: 11, audioBitrate: "192k" }` | final encode and loudness target |
| `tts` | `{ "voice": "af_heart", "dtype": "fp32", "speed": 1 }` | `pnpm tts` (Kokoro): voice (`pnpm tts --list-voices`), model variant `fp32` (default, fastest) / `q8` (smaller download, 2.3× slower) / `fp16` (broken on the CPU: NaN output) / `q4`, `q4f16` (untested), speaking speed; benchmark in `../tools/kokoro.md` |
| `align` | `{ "model": "onnx-community/whisper-base_timestamped", "dtype": "fp32", "language": "en" }` | `pnpm align` (Whisper via Transformers.js): model (only `onnx-community/whisper-*_timestamped` give word times; `whisper-small_timestamped` for hard audio), variant, language code – no auto-detection, so Norwegian audio needs `"align": { "language": "no" }`. Writes `<dirs.audio>/<audio file>.words.json` per scene: measured `[start, end]` per voice word, plus the audio size/mtime and text it was made from |
| `captions` | `{ "maxChars": 84 }` | SRT captions (`pnpm captions`, assemble): a sentence longer than `maxChars` is split at the last `, ; :` before the limit, else at a word boundary |
| `scenes` | `null` = every `NN-*.html` in `dirs.scenes`, name order | scene list (below) |

`fps`, `width`, `height`, `lead`, `tail`, `page`, `camBase`, `cursorRest`, `hover`, `columnTable` and `theme`
reach the browser only through `shared/voice.js` (`const VIDEO`). Run `pnpm voice-meta` after changing them.

Scene list entries (`scenes: [...]`), in video order:

| Key | Meaning |
|---|---|
| `id` | number (key = zero-padded to 2: `4` → `"04"`) or string |
| `slug` | name part; default = key |
| `file` | scene HTML in `dirs.scenes`; default `<key>-<slug>.html` |
| `clip` | clip file in `dirs.clips`; default `<key>.mp4` |
| `audio` | explicit file in `dirs.audio`; `"none"` or `null` = no audio |
| `silent` | `true` = no voice; length from `duration` (default 3 s) |
| `duration` | silent scene length, or speech seconds of a dummy voice (text, no audio file) |
| `text` | literal voice text (wins over `voiceText`) |
| `paragraph` | 1-based paragraph of `voiceText`; otherwise the next unused paragraph in scene order |
| `lead`, `tail` | per-scene override of the global values |

### Worked examples

Four scenes: voiced (takes the next unused paragraph of `voiceText`), a silent title card, a scene with its own ElevenLabs file, a scene with literal text:

```json
"scenes": [
  { "id": 1, "slug": "intro" },
  { "id": 2, "slug": "title", "silent": true, "duration": 4 },
  { "id": 3, "slug": "billing", "audio": "3_Billing.mp3" },
  { "id": 4, "slug": "users", "text": "Open the list to see every user." }
]
```

Retake of scene 4 after its voice text changed (new wav, new word times, new metadata, re-render):

```bash
pnpm tts --scene 4 --force
pnpm align --scene 4
pnpm voice-meta
pnpm render scenes/04-users.html
```

One scene with its own overlay look: there is no per-scene `theme` key in the config, so set it in that scene's `createDemo` (preset name, or an object merged over the config theme – see [ENGINE-API.md](ENGINE-API.md) › Themes):

```js
createDemo({ /* … */ theme: "spotlight" });                 // preset
createDemo({ /* … */ theme: { highlight: { pad: 6 } } });   // overrides only
```

## Commands

| Command | Does |
|---|---|
| `pnpm tts [--scene 2,5] [--force] [--voice …] [--dtype …] [--speed …]` | offline Kokoro voice: writes `audio/NN-slug.wav` for every voiced scene from the voice text; skips scenes that already have an audio file (`--force` regenerates only its own wav, never another file). `node tools/tts.mjs --text f.txt --out f.wav` synthesises one text file and prints generation time and real-time factor; `--list-voices` lists the voices |
| `pnpm align [--scene 2,5] [--force] [--model …] [--dtype …] [--language en]` | measured word times: Whisper transcribes each voiced scene's audio offline and aligns it to the voice text, writing `audio/<file>.words.json`. Run after `pnpm tts` or a new recording, before `pnpm voice-meta`. Measured words are about 0.1 s; without them the estimate is usually within 0.2 s in short paragraphs with clear pauses, but it drifts up to several seconds in long paragraphs. Skips a scene whose sidecar matches audio and text (`--force` measures again); under 50 % matched words writes nothing and exits 1, under 80 % warns. First run downloads the model (~291 MB) into `WHISPER_CACHE_DIR`, else `~/.cache/skill-c2v/whisper`. `node tools/align.mjs --audio f.wav --text f.txt --out f.words.json` aligns one file |
| `pnpm voice-meta [--config <file>]` | measures audio (ffmpeg: duration + silencedetect), writes `shared/voice.js` and `shared/voice.json`; adds `words` (measured times) from a matching `.words.json`, warns on a stale one |
| `pnpm render scenes/04-users.html` | renders `clips/04.mp4` with voice |
| `pnpm render scenes/04-users.html --stills 0,3.5,end` | PNG stills `stills/04-0.png`, `04-3.5.png`, `04-end.png` |
| `pnpm stills scenes/04-users.html` | stills at `0` and `end` |
| `pnpm contact scenes/04-users.html [--after 0.5]` | contact sheet `stills/04-contact.png`: one labelled still per `cue()` the scene asked for (and one `--after` s later, default 0.5, `0` = none), per click, camera key, highlight start and move end, plus the first and last frame – the quickest check that every beat lands on the right words. `--all` makes one sheet per scene |
| `pnpm render:all --jobs 4` | every scene in config order (missing files skipped with a warning) |
| `pnpm check` / `pnpm check --clips` | boundary check from scenes / from rendered clips |
| `pnpm assemble [--out file.mp4] [--config file]` | joins `clips/` into `output`: one re-encode, two-pass loudnorm (skipped with a note when every clip is silent – the file still gets a silent stereo track), length capped at the clips' total frames ÷ `fps` so AAC padding never lengthens the video; silent and voiced clips mix freely. With `shared/voice.json` and any voice text it also writes `<output>.srt` (as `pnpm captions`, timed by the joined clips) |
| `pnpm captions [--out file.srt] [--config file]` | SRT captions from `shared/voice.json` (`tools/captions.mjs`): one caption per sentence (split by `captions.maxChars`), from first word − 0.1 s to last word + 0.25 s (≥ 1 s), offset by each clip's start (measured frames of `clips/NN.mp4`, else `round(duration × fps)` – works before rendering); default `<output>.srt` |
| `pnpm doctor [--config file]` | checks Node version, ffmpeg, a launchable browser and the font bundle; exits 1 when rendering cannot work. Also shows (informational) whether kokoro-js is installed and the Kokoro model for `tts.dtype` is cached |
| `pnpm example` | end-to-end proof: synthetic voice (`examples/make-audio.mjs`, when missing) → voice-meta → render all → assemble → probe of `examples/example.mp4` |
| `pnpm test` | `tools/*.test.mjs`: `cue.mjs` vs `makeCue` in `engine.js`; `resolveTheme`/`THEME_PRESETS`; contact-sheet planning and layout; ffbin, voice-meta and assemble against small clips generated with the bundled ffmpeg; caption grouping, timing and SRT (`captions.mjs`); word alignment and scene/audio resolution (`align.mjs`, no model needed); the link validator (no browser needed) |
| `pnpm links [--external]` | validates every Markdown link and backtick file path in the skill (`..`); `--external` also HEAD-checks http(s) links |
| `pnpm ffmpeg …` | runs the bundled ffmpeg (`tools/ffbin.mjs`), e.g. `pnpm ffmpeg -i clips/03.mp4` to list streams and duration |

`render.mjs` flags: `--stills <list>` (seconds or `end`, comma-separated), `--contact` (+ `--after S`), `--all`, `--check-boundaries`,
`--clips` (with `--check-boundaries`), `--jobs N` (default `min(4, cores/2)`), `--capture png|jpeg`
(default `encode.capture`), `--quality N` (JPEG, default 95), `--out <file>` (one scene only),
`--config <file>`. A scene may also be an `http(s)://` URL (e.g. a served React harness); its relative
`audioSrc` is resolved against the scenes folder, then by file name in `dirs.audio`. `window.DEMO` is awaited
for up to 10 s, so a scene may create it after asynchronous loading (e.g. 3D assets).

## Scene file anatomy

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>04 – users</title>
  <link rel="stylesheet" href="../fonts/fonts.css">
  <link rel="stylesheet" href="../base.css">
  <link rel="stylesheet" href="../shared/product.css">
</head>
<body>
  <div id="stage"><div id="camera"><div id="page">
    <!-- app page markup, or built by components.js below -->
  </div></div></div>
  <script src="../shared/voice.js"></script>
  <script src="../engine.js"></script>
  <script src="../shared/data.js"></script>
  <script src="../shared/components.js"></script>
  <script>
    const S = sceneInfo(4);                       // duration, lead, tail, audio, cue from voice.js
    createDemo({
      duration: S.duration, lead: S.lead, audioSrc: S.audioSrc, audioDuration: S.audioDuration, cue: S.cue,
      moves:  [{ t0: S.cue("open the list") - 1.1, t1: S.cue("open the list"), to: { sel: "[data-nav=users]" } }],
      clicks: [{ t: S.cue("open the list") + .3 }],
      states: [(t) => fadeIn(".user-list", S.cue("open the list") + .35, .2, t)],
    });
  </script>
</body>
</html>
```

`#stage`, `#camera`, `#page`, `#highlights`, `#ripple` and `#cursor` are created when missing. Add
`explode/explode.js` (path relative to the scene file) after `engine.js` when the scene uses the exploded view. Runnable examples:
`examples/01-example.html` (silent, fixed times) and `examples/02-voiced.html` (voiced: `const S = sceneInfo(2)`,
then `S.cue("open the panel")` etc. for every time, `duration: S.duration, lead: S.lead, audioSrc: S.audioSrc`).
The example voice is generated: one soft tone per sentence of `examples/audio/voice-script.txt` with pauses
between, so voice-meta measures real pauses and the cues anchor to them as with a recording. `pnpm example`
builds the whole example video; delete `examples/audio/02-voiced.mp3` to regenerate the voice.

### Captions

Burned in: add `captionTrack(S)` as the last entry of `states` (`examples/02-voiced.html` does). It shows the
sentence being spoken in `#captions` (on the stage, not zoomed) and nothing after the voice ends, so the last
frame stays clean. Options in [ENGINE-API.md](ENGINE-API.md) › Voice. The default look is neutral on purpose:
set it per video in `shared/product.css` `:root` with `--caption-font`, `--caption-size`, `--caption-weight`,
`--caption-color`, `--caption-bg`, `--caption-radius`, `--caption-pad`, `--caption-max`, `--caption-now`,
`--caption-said`, `--caption-ahead` (see `product.template.css`). `mode: "karaoke"` marks word by word and only
looks right with measured word times (`pnpm align`); with estimated times words drift by up to ~0.2 s.
As a file: `pnpm assemble` writes `<output>.srt` next to the video; `pnpm captions` writes it alone.

## Live preview

Open the scene file in Edge/Chrome. The stage is scaled to fit the window and plays in a loop with the
voice. Keys: Space pause/play, ←/→ ±1 s (Shift: one frame), Home to 0. Click once if the browser blocked
audio. The HUD shows `t / duration`. `?t=3.2` shows one static frame; `?render` disables the preview
(used by render.mjs). The preview clock is the only use of wall time; frames stay functions of `t`.

## Rendering internals

- Each scene opens in its own browser context (viewport = config size, device scale 1) with `?render=1`.
  render.mjs waits up to 10 s for `window.DEMO` and fails with `window.DEMO mangler` when `createDemo` did not run.
- Font check: every `@font-face` is loaded explicitly and every family in `fonts` must have a loaded face,
  else the scene fails (`fonter ble ikke lastet`). Network fonts fail intermittently headless and change
  layout mid-render – keep fonts in `fonts/`.
- Frames: `round(duration × fps)`; frame f is `seek(f / fps)` + a CDP screenshot (JPEG q95 by default,
  stills always PNG).
- Contact sheet (`--contact`): `tools/contact.mjs` plans the tiles from `DEMO.cues()` and `DEMO.events()` (merged
  when closer than half a frame, clamped to the scene), render.mjs grabs each as PNG and screenshots a generated
  HTML grid (4 columns, time, labels and camera/cursor state per tile) in a second page of the same context.
- `--jobs N`: a scene is split into up to N frame ranges of ≥ 1.5 s; N worker pages render and encode
  ranges in parallel (x264 `encode.crf`/`preset`, yuv420p, BT.709, tv range); ranges are joined without
  re-encoding and the voice is muxed (delayed by `lead`, padded, AAC 192k 48 kHz stereo; silent track when
  there is no audio). ffmpeg then counts the clip's frames (stream copy, no decoding) to verify them.
- Per clip the start and end state (camera `s cx cy`, cursor `x y`) and `DEMO.lint()` warnings are printed.
  Lint compares the first and last frame with their neighbours: element mid-animation (inline
  opacity/transform/display/visibility differs), highlight visible, click ripple visible, cursor mid-move,
  camera moving. Each means the cut will show motion.
- Boundary check: last frame of N vs first frame of N+1, rendered from the scenes (or decoded from the
  clips with `--clips`). A pixel deviates when any channel differs by more than 24; the cut passes when at
  most 0.001 % of the pixels deviate (21 px at 1080p). Prints PSNR, the deviating box and both states;
  failing pairs are saved as `stills/NN-end.png` / `stills/MM-0.png`.

## Using other libraries deterministically

Libraries are allowed when they run paused and are driven by `t` inside a `states` function – never with
their own clock. See `../tools/gsap.md`, `../tools/threejs.md` and `../tools/motion.md`.

## Troubleshooting

Every error message (`window.DEMO mangler`, `fonter ble ikke lastet`, `cue(): fant ikke`, browser or ffmpeg
not found, Kokoro and align errors), lint and boundary warnings, with cause and fix: [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
